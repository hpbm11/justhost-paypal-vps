## PayPal 比其他付款方式少掉哪些麻烦

跨境买主机最常见的三个卡点是货币转换、被风控标记、外币交易手续费。用 PayPal 余额或绑定的银行账户付款，这三样基本被 PayPal 接走了。

| 维度 | PayPal | 直接刷卡 | 银行转账 |
| --- | --- | --- | --- |
| 卡号是否交给商家 | 否 | 是 | 否 |
| 服务未交付时的救济 | 可发起争议（Dispute） | 只能找发卡行拒付 | 基本没有 |
| 支持自动续费 | 是 | 是 | 一般不支持 |
| 争议在几个平台解决 | 1 个 | 2 个（银行 + 商家） | 无 |

卡号不落到商家服务器这一点，对买 VPS 尤其实际。你可能同时在四五家小商家挂着机器，每家都要填一次卡号，任何一家泄露都牵连到你所有订阅。PayPal 只把授权结果告诉商家，卡号留在 PayPal 那边。

争议通道是另一个价值。VPS 是预付制服务，付了钱机器没开、或者配置严重不符，直接刷卡的解决路径是找发卡行拒付，流程长且要反复举证；走 PayPal 可以在平台内开争议，订单号、工单记录都在一个地方。需要说清楚的是，虚拟服务的争议结果不完全由买家决定，开争议前把订单截图和工单往来留好，比什么都管用。

## 三个容易出错的地方

**自动续费默认是开的。** 你在结账时授权的是循环扣款，每个计费周期到期会自动扣一次。这不是坑，但如果你只想用一个月测试，记得去 PayPal 后台的「自动付款」里找到这笔授权并取消，或者在商家客户区关掉自动续费。取消授权不影响已经付过的这一期。

**人民币余额付美元订单有汇率转换费。** PayPal 会把美元金额按自家汇率折算成人民币扣款，这个汇率比银行牌价略差一点，等于隐形成本。订单金额小的时候几毛钱，年付大额套餐就值得算一下。账户里有美元余额的话直接扣美元更划算。

**首次绑定 PayPal 可能触发额外验证。** 一般只在第一次设置时发生一次，按提示走完就行，后面续费不会再问。

**1 核 2G 或 2 核 2G（$4.61 / $5.99）** 适合跑 MySQL 加应用、同时开两三个 Docker 容器、或者要做定时任务和备份。多花一两美元买到的是不因为内存不足被 OOM 杀掉进程的安稳。

**4 核以上基本是给特定负载准备的。** 持续编译、视频转码、跑多个数据库实例、做 CI runner，这些才需要往上加。**如果你只是想搭个站或者跑个代理，8 核 16G 那几档跟你没关系。** 同样的预算，把钱花在换更好的机房位置上，比花在核数上对体验的提升大得多。

## 退款、续费、IPv6：下单前确认三件事

**退款。** 公开页面上没有看到明确的退款窗口说明，这一点必须在下单前自己去官网的条款和 FAQ 里确认。年付套餐金额大，尤其要先看清楚。真遇到服务未交付或与描述严重不符，PayPal 侧的争议通道是可以用的，这也是走 PayPal 而不是转账的实际意义。

**续费价。** 月付按月扣，压力小、随时能停，适合第一次试。年付通常有折扣，但折扣只作用于当期还是续费同价，各家做法不同，结账页会显示下一个周期的金额，付款前扫一眼那个数字。

## 常见问题

**付完多久能拿到机器？**
自动开通，通常在付款后几分钟内，开通邮件里有 IP、root 密码和 SSH 端口。超过半小时没收到，查垃圾邮件文件夹，再提交工单。

**能不能只用 PayPal，不绑信用卡？**
可以。PayPal 账户里只要有余额或已绑定的银行账户就能付，不需要在 JustHost 侧填任何卡号。这也是很多人选 PayPal 的主要原因。

**续费还能继续用 PayPal 吗？**
可以。开了循环扣款就每个周期自动从 PayPal 扣，不想自动扣就在 PayPal 后台取消授权，下个周期手动付。

**VPS 和独立服务器怎么选？**
需要硬件完全隔离、要跑满 CPU 不被邻居影响，选独立服务器。只是建站、跑容器、做代理、练手，VPS 的性价比高得多。

**支付宝和 PayPal 哪个更划算？**
看你的账户结构。有美元余额或绑定外币卡，PayPal 直接扣美元最省。只有人民币，两种方式都会涉及一次汇率转换，差别不大，选习惯的那个。
